# Project guardrails

## Scope and workflow

- Archetype Cab Disabler edits Neural DSP desktop plugin presets; Quad Cortex is out of scope. Keep the repository slug and canonical repository `Metarch-Ancilla/Archetype-Cab-Disabler` stable. Runtime names are `Archetype Cab Disabler.exe` and `Archetype Cab Disabler.app`.
- Use the existing isolated checkout. Do not create a worktree unless requested.
- Never use GitHub Actions: do not create, trigger or inspect workflows, runs or jobs. Keep `.github/workflows` absent. Run validation locally in the attached environment; GitHub stores source and releases.
- Source/documentation-only requests must not compile or package applications. Syntax-only checks are allowed when relevant. For authorized desktop builds, read `.agents/skills/cloud-desktop-build/SKILL.md`; use the default prerelease profile, reserving `--profile full` for stable releases, release candidates or explicit deep validation.
- Run native differential/workflow checks after backend changes. Reuse successful validation for documentation/frontend-only follow-ups; run Wine or other platform checks only for relevant changes. Do not run a syntax-only pass immediately before real compilation.
- Distinguish current source from published downloads. Cross compilation and Wine do not establish native OS/architecture compatibility. See [validation](docs/VALIDATION.md), [architecture](docs/ARCHITECTURE.md) and [security](docs/SECURITY.md) for current evidence and limits.
- Do not commit or bundle private user presets or custom comparison exports. Factory presets are publicly available from official Neural DSP desktop plugin installers; comparison exports generated in the plugin are separate material, not claimed installer-distributed files. Use generated public fixtures and local private verification where needed.

## Shared engine and file safety

- Keep parsing, discovery, selection, review, backups and writes in the shared C++17 backend under `native/backend/`. Native Win32 and AppKit frontends render models and use the private pipe protocol; do not introduce separate platform edit engines, Tk/Tcl, PyObjC or webviews.
- Use `shared/text.hpp` for UTF-8/hex/line framing, `shared/channel.hpp` for bounded asynchronous channels and `shared/version.h` as the canonical application version. No Python runtime, runtime network access, plugin loading, telemetry or history database.
- Detect formats structurally across plugin identities/versions. Do not gate editing on plugin names, version whitelists or schema hashes. Exactly one unambiguous whole-cab scalar may change, including its necessary serialized length. Preserve every other byte, including names, versions, IDs, paths and amp/mic/IR state. No whole-tree serialization, decryption or arbitrary byte searching. Unknown, encrypted and ambiguous inputs remain untouched.
- Direct Edit writes the existing opened file, preserving inode/ownership and requiring file write access rather than parent-directory write access. Recheck reviewed identity/hash before writing, then flush/fsync and verify read-back. No replacement file, chown, ACL copying or owner-mismatch rejection. Direct writes are non-atomic.
- Copy and Edit publishes atomic, no-clobber copies below each library's `Cab Disabled` or `Cab Enabled` folder according to the selected operation. Preserve relative folders, filenames, extensions and embedded metadata exactly; never add/strip `CD` or rename originals. Exclude both generated folders from discovery and recursive copying.
- Reject symlinks/reparse points throughout path traversal. Discovery metadata is observational; it never authorizes a later write. Keep operation-scoped directory anchors and fresh identity/hash checks.
- Backup is an explicit Yes/No choice. Default to Desktop; Browse chooses a future ZIP destination and never overwrites an existing backup. Names are `neural_dsp_presets_YYYY_MM_DD.zip`, then `_2`, `_3`, etc. Preserve archived preset/folder names and the manifest. Reopen the complete ZIP and verify every entry/hash before the first edit or elevation request. Backup failure/cancellation means zero edits.

## Privilege and platform boundaries

- GUI, backend and backup creation stay at ordinary user privileges. At Apply, after backup verification, probe the exact selected files without modifying them. Request native authorization only if Direct Edit needs it; Copy and Edit never prompts. Authorization cancellation/failure means no edits.
- Authorize only reviewed selected regular XML paths, with no folder-root restriction and no linked path components. A one-batch native helper returns file descriptors/handles to the ordinary backend, which rechecks identity/hash and edits the scalar. No root backend, elevated GUI, shell commands, service, persistent daemon, permission/ACL changes or privileged backup writes.
- Windows packages one EXE with the backend and authorization bridge linked in. Dispatch ordinary-user `--backend` and restricted `--privileged-helper` before GUI startup; keep the manifest `asInvoker`. UAC uses explicit `runas`, a selected-file allowlist, a private local-only pipe with current-user/admin/System DACL, and both peer PID checks. Do not restore standalone helper/backend executables, DLL extraction or loose runtime notices.
- macOS retains its one-batch native helper/bridge with versioned PID handshake, deadlines, cancellation and bounded specific-child reaping. Replacement of its deprecated elevation API is deferred. Publisher signing/notarization is declined; retain ad hoc Mac signing and do not make paid signing a release prerequisite. Windows releases remain unsigned. Hash verification does not establish Apple trust or notarization; downloaded Mac apps may encounter Gatekeeper quarantine.
- Target Intel macOS 10.13 and Apple Silicon 11.0, including every dependency and AppKit API. Keep native file APIs instead of introducing a newer `std::filesystem` runtime dependency. macOS uses system libc++, static Expat and four universal Mach-O files; Windows statically links its C++ runtime and Expat.
- Increment the embedded application version for functional changes and keep backend, resources, build metadata and release names consistent. When `shared/version.h` changes, run `.venv/bin/python scripts/generate_licenses.py` and include refreshed versioned notices before building. Upload matching platform notices with releases. Mac ZIP names include the application version.

## Current interface rules

- Keep the six-page Next/Back wizard and installer-sized initial window (roughly 600×460), top-aligned forms and bottom-anchored navigation. Tables/review fill available height. No Cancel button; window close cancels. Finish closes the results page; no report export or New operation.
- Open immediately on Select Plugins with an empty table and inline `Indexing...` beside the title, in the normal Browse-label font; repeat after Browse. Discover preset folders only and hide default roots. Browse prompt is `Preset folders not detected?`; accept plugin roots with nested Presets.
- Both selection pages have an unlabeled global mixed-state header checkbox and no Include heading. Preset trees have expandable checkbox folders/files, folders before loose presets at every level, and horizontal separators only between plugin groups. Show preset stems without `.xml`; never strip folder suffixes. Column heading is Presets. Checked user presets are supported in both edit modes.
- Put `Create backup?` and Yes/No on one row. Location is a read-only white field with grey border, sized to wrapped content with one line by default. No disables Location and Browse.
- Edit Mode has exclusive Enable/Disable and Direct Edit/Copy and Edit checkbox pairs, supporting all four combinations. One white, grey-bordered description box below the edit-mode buttons updates immediately: cab action first, edit description second, and `Direct edit may require elevated permissions.` on a third logical line only for Direct Edit. Keep a blank line above the box; no separate description below cab buttons.
- Review shows Mode, Backup, Operation and Presets count as separate unboxed lines, followed by a bordered relative plugin/folder/file tree. Separate plugin roots with blank lines; omit full paths and readiness messages. With No backup, show exactly `Backup not enabled. Proceed at your own risk.` as unboxed information just above navigation. Use a native warning icon, vertically centred, at Windows system small-icon size or 16 points on Mac. Do not block Apply or require acknowledgement; keep other general warnings in README.
- Progress is static `Working... X/Y` text, without animation or a graphical bar. Successful live status is `File: <preset stem>`; retain failure/already-correct context. Update status on STATUS/PROGRESS or complete snapshots, never per OPTION row.
- Results show Successful/Failed counts and a separate relative tree with errors/reasons and Already enabled/Already disabled context. Put Errors above/outside the box. No full file locations.
- Windows uses native Win32 scrollbar behavior: no custom auto-hide, hover timers, scrollbar-style interception, outer-page scrolling or restored ScrollbarProc/controller. Native content controls own ranges/visibility. Selection pages have no horizontal bars; Review wraps without a horizontal bar. Both tables use separate native headers with full drag, fixed checkbox columns and persistent bottom separators; plugin widths fit the viewport with native vertical-bar width reserved. Refresh preset location painting during column tracking.
- Windows checkboxes use native theme drawing and a single owner-drawn header path for enabled, disabled, focused and mixed states. Keep checkbox alignment fixed across tree depths and prevent duplicate native toggles after shared-model input. Buffer tree painting, clip parent/sibling painting around children and redraw all children after rebuilding controls. Inspect real captures, including disabled indexing, when changing drawing.
- Mac uses standard Aqua/light appearance, including dialogs/licenses, with white boxed fields. Activate cross-view constraints only after views share an ancestor; disable native outline grids and expand/collapse animations, and draw plugin separators at one backing pixel. Double-click expands preset rows with children without changing selection. Disabled backup paths use `disabledControlTextColor` and disable selection/Browse. Review preserves lines with content-sized horizontal scrolling only when needed; results wrap.
- Keep Licenses independently inset at the top/right in the normal 13-unit font. License viewers preserve lines without wrapping, size initially to content within the work area, and allow horizontal scrolling. Windows uses system Msftedit Rich Edit and embedded RCDATA 102 notices; its ZIP contains only the application EXE.
